# Your Approved Project Title
BrightCoco

## Summary
BrightCoco is a web-based system for coconut farmers who have difficulty
identifying coconut varieties. The system aims to give
farmers an easy way to identify these problems and find guidance, helping
them protect their crops and improve their harvest.


## Current stack
- **Implemented now:** Flutter Web / Dart (starter screens: Home and Login)
- **Planned:** REST API (instructor-approved backend, e.g., FastAPI) and PostgreSQL
- **Version control:** Git + GitHub

## Project structure
The Flutter project is inside the `semester_project/` folder.

lib/

## Run locally
Requires Flutter SDK and Google Chrome.

    git clone https://github.com/arnelabian-sys/act8_flutter.git
    cd act8_flutter/semester_project
    flutter pub get
    flutter run -d chrome
